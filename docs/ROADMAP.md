# Gameplay direction

The goal is a fun, playable crazy run with a small set of connected systems:
inventory → mining → crafting → combat/procs → loot and mobs. Expand interactions
after they work together; the larger idea bank is not a sequential first-release
requirements list.

Immediate priorities:

1. Normal .37 run acceptance: F5, inventory, mining, melee, armor and shields.
2. Public build reproducibility, local asset preparation and an installation path.
3. MC mob navigation/combat on native terrain and additional useful build interactions.

Required future content includes recognizable zombies/creepers, a Wither boss,
and friendly summons such as a dog that fights for the player. Cross-game item,
ability, mob and crafting interactions are the main design direction.

Native RoR2 floor mining is explicitly deferred. External Minecraft shader-pack
support is an exploratory idea, not implemented compatibility. **Multiplayer is
the final major goal**, after singleplayer ownership/state/damage are stable.
